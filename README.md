# MTZ Installer

Установщик тем `.mtz` для MIUI и HyperOS (Xiaomi / Redmi / POCO).

## Что умеет

- Выбор `.mtz` через проводник, «Открыть с помощью» и «Поделиться»
- Превью темы (обложка, экран блокировки, рабочий стол, иконки…)
- Название, автор, дизайнер, версия, версия UI, размер
- Состав темы: иконки, шторка, шрифты, обои, экран блокировки и т.д.
- Библиотека импортированных тем — можно переустановить в любой момент
- Быстрый возврат темы, если MIUI её сбросила: кнопка «Вернуть», ярлык на рабочем столе
  и плитка «Вернуть тему» в шторке
- Проверка прошивки (MIUI / HyperOS) и наличия приложения «Темы»
- Три способа установки с автоматическим переходом к запасному:
  1. **Прямое применение** — открывает `ApplyThemeForScreenshot` в «Темах»
  2. **Открыть в «Темах»** — передаёт файл через FileProvider, без доступа к памяти
  3. **Скопировать** — кладёт файл в `Загрузки/MTZ Installer` и открывает «Темы»
- Material You, тёмная тема, Android 7.0+

## Как собрать APK

### Вариант 1 — GitHub (можно с телефона)

1. Создайте новый репозиторий на github.com.
2. Загрузите в него содержимое этой папки (Add file → Upload files).
   Папку `.github` тоже — без неё сборка не запустится.
3. Откройте вкладку **Actions** → «Build APK». Сборка запустится сама после загрузки
   (или нажмите **Run workflow**).
4. Через ~5 минут откройте завершённый запуск → внизу **Artifacts** → `MTZInstaller-apk`.
   Внутри zip лежит `app-release.apk`.

### Вариант 2 — Android Studio

Откройте папку проекта → дождитесь синхронизации Gradle → **Build → Build APK(s)**.

### Вариант 3 — прямо на телефоне

Откройте проект в AndroidIDE / Code Studio и запустите сборку `assembleRelease`.

## Заметки

- APK подписан debug-ключом — для личного использования этого достаточно.
- На Android 11+ для способов 1 и 3 приложение попросит «Доступ ко всем файлам»:
  системным «Темам» нужен путь к файлу в общей памяти.
- Поведение «Тем» отличается между версиями MIUI/HyperOS: если тема не применяется,
  выберите другой способ кнопкой «Способ…».
