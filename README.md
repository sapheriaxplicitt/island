# Spotify Island

Плавающий остров сверху экрана для Windows: часы → мини-плеер → развёрнутый плеер с текстом песни,
цветами обложки и точечным визуализатором, плюс системные уведомления в стиле iOS.

## Музыка
Читает системный медиа-слой Windows (SMTC): Spotify, YouTube и любые сайты в Chrome/Edge/Firefox, Spotify-приложение.
Не нужны ни вход, ни ключи, ни Premium. Кнопки и перемотка идут через Windows.
Если сайт не отдаёт длительность, время считается по ходу воспроизведения, перемотка по точкам отключается.

## Системные события
Интернет пропал/вернулся, Wi-Fi, VPN (по адаптеру), зарядка/питание/низкий заряд/заряжено,
подключение и отключение наушников и колонок (в т.ч. Bluetooth), флешки.
Оранжевая точка слева — микрофон используется, зелёная — камера.

## Тексты песен
Параллельно из LRCLIB, LRCLIB-поиска, NetEase и Kugou. Первый подходящий вариант показывается сразу,
затем таймкоды сверяются между источниками (по совпавшим строкам) и проверяется длительность трека.
Результат кэшируется на диск.

## Свои уведомления
    curl -X POST http://127.0.0.1:8765/notify -d "{\"title\":\"Привет\",\"text\":\"Текст\",\"icon\":\"💬\",\"kind\":\"ok\",\"right\":\"5 мин\"}"
kind: info | ok | warn | bad. Системные уведомления самой Windows читать нельзя, поэтому только свои и перечисленные выше.

## Запуск
    npm install
    npm start
EXE собирается в GitHub Actions (вкладка Actions → артефакт SpotifyIsland).
Трей: клик — показать/скрыть, правый клик — автозапуск и выход.
